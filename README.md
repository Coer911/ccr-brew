# Cultura Brew

Приложение для заваривания кофе: пошаговый таймер с анимацией пролива, учёт зерна,
дегустационные заметки. Интерфейс на русском, цены в рублях.

> **Cultura Brew — модифицированная версия [Brew Guide](https://github.com/chuthree/brew-guide)**

> Исходный код этой версии открыт на тех же условиях.

## Что изменено относительно оригинала

Оригинал: `chuthree/brew-guide` @ `419f453` (первый коммит этой ветки — без изменений).

- Интерфейс переведён с китайского на русский (~3 100 строк), валюта ¥ → ₽.
  Инструменты перевода — `scripts/i18n/` (переводы в `scripts/i18n/ru/*.tsv`).
- Текстовый экспорт/импорт зерна и рецептов — на русском; импорт старых китайских текстов тоже работает.
- Название и метаданные — Cultura Brew; `lang="ru"`.
- Убраны: ссылки на App Store / APK / десктоп-сборки автора, проверка обновлений
  с сервера автора, QR-коды сообщества и донатов, список спонсоров, ссылки на сайт автора.
- Пошаговая настройка WebDAV — на примере Яндекс Диска.
- В «О приложении» — указание на оригинал и лицензию.

Не переведено (не видно пользователю): логи разработчика, промпты ИИ-распознавания,
SQL-скрипт Supabase. Распознавание по фото использует сервер автора и в этой сборке
не настроено.

## Запуск

```bash
pnpm install
pnpm dev            # http://localhost:3000
pnpm test           # 242 теста
pnpm build          # статичный сайт в out/
```

## Dockhost

Это статичный сайт, сервер и база не нужны: данные хранятся на устройстве пользователя.

```bash
docker build -t cultura-brew .   # nginx на порту 8080
```

На Dockhost: репозиторий → `Dockerfile` из корня, порт контейнера `8080`,
маршрут на бесплатный домен. Чтобы открыть из Telegram: @BotFather → @Brewing_ccrbot →
Bot Settings → Menu Button → URL домена.
